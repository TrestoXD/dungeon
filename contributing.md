# Contributing to Dungeon

First off, thank you for checking out Dungeon! We are building a 3D Dungeon Game and engine in Rust from scratch, and we welcome contributions from the community to make it better.

## Our Philosophy & License

Dungeon is open-source software licensed under the **GNU GPL v3**. This ensures that the code will always remain free and open for everyone. 

Following models like **Krita**, our development and repository are 100% community-driven and free, while we also distribute pre-compiled, optimized versions on official stores (like Steam) for a small fee (around €7-8) to fund continuous development, server costs, and support the project's sustainability.

By contributing code, documentation, or assets to this repository, you agree that your contributions will be licensed under the GNU GPL v3 and bundled into all official distribution channels, including free builds and paid store releases.

## How Can I Contribute?

### 1. Reporting Bugs & Suggesting Features
Before opening a new issue, please search the existing ones to see if it has already been reported. If not, feel free to open a new issue and include:
* A clear and descriptive title.
* Steps to reproduce the issue (if it's a bug).
* Your OS and environment details.
* What you expected to happen vs. what actually happened.

### 2. Submitting Pull Requests (PRs)
1. **Fork** the repository and create your branch from `main`.
2. Ensure your Rust code is properly formatted using `cargo fmt`.
3. Run `cargo clippy` to check for common linting issues.
4. Keep your commits clean and write meaningful commit messages.
5. Open a Pull Request with a clear description of your changes.

## Code of Conduct
We aim to maintain a welcoming, respectful, and collaborative environment. Please treat all contributors with kindness and respect.
